# portfolio</br>
• 프로젝트 목적: 본인의 백엔드 기술 역량을 증명하기 위해 PHP 아키텍처로 직접 구축한 포트폴리오 웹사이트입니다.</br>
• 사용한 기술 사양: PHP (Pure PHP), MySQL</br>
• 핵심 구현 기능:</br>
　PDO 객체를 활용한 데이터베이스 연동</br>
　admin 폴더 내 게시판, 검색, 페이징 표시</br>
　회원가입, 로그인, 로그아웃 등 회원 관리</br>
　html, CSS, jQuery, bootstrap을 활용한 프론트엔드 구현</br>
</br>
• portfolio</br>
　└admin : 로그인, 글 등록, 수정</br>
　└works : 포트폴리오 내 사이트의 html, css 모음. 데이터베이스 기반 화면 표시</br>
　　└caravan : 데이터베이스를 사용하지 않은 페이지, 오픈 소스를 사용한 슬라이드 커스텀</br>
　　└carehelp</br>
　　　└app : 하이브리드 어플리케이션 작업물의 일부. COOKIE 저장 방식의 입력 form, 조건에 따른 상태 변화</br>
　　└manager : 데이터 베이스 기반의 메인 페이지, 오픈 소스와 영상 사용한 슬라이드 커스텀</br>
　　└moneypig</br>
　　　└admin : 작업한 admin 페이지의 일부. 회원가입, 회원관리, 로그인, 게시글관리, 정산, 엑셀 다운로드</br>
　　　└report.php : 월별 성과 보고서, 달력 작성의 응용</br>
　　└pickme : 데이터 베이스 기반의 메인 페이지, 오픈 소스를 사용한 슬라이드 커스텀
